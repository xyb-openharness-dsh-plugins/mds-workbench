# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：骨髓增生异常综合征（MDS）患者及家属照护者；以老年患者为主、家属常代管资料；含低危长期观察等待者、去甲基化药物治疗者、移植评估前后的家庭；患者组织志愿者协作使用

场景：确诊依据档案（血象、骨髓穿刺/活检、细胞遗传学、分子检测结果登记不判读）；低危与高危路径的随访节律与血象趋势；输血按次记录（成分、单位数、输前血红蛋白）与近 90 天输血节奏；血清铁蛋白趋势与铁螯合用药记录；去甲基化药物疗程折叠卡与疗程内血象最低点；血细胞减少日常观察（感染防护/出血/疲劳，只呈现医生确认的医嘱原话）；医保与就诊材料；家属协同记录（默认私密）

核心流程：
1. 选择本机资料目录并导入血常规/骨髓报告/出院小结等检查资料
2. 核对候选信息，建立确诊依据档案与检查结果登记
3. 记录血象随访、输血次数与铁蛋白趋势
4. 整理疗程档案与日常观察记录
5. 生成复诊准备与就诊沟通材料

完成结果：得到来源可追溯、可核对的个人病程档案：确诊依据登记、血象随访趋势、输血与铁监测记录、疗程档案、复诊准备材料；所有候选信息经用户核对入档，不提供诊断、危险分层或治疗建议

初始布局选择：business-first
