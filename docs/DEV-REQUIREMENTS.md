# DEV-REQUIREMENTS · 小髓宝 MdsPal

- 版本：v0.1.0 · M0 起草，随里程碑追加（每条带错误来源）

## 一、家族硬约束（全部适用）

- 原型是唯一视觉与交互基准，开发版逐项对齐（ui-parity 逐字符）；公开包 `public/` 与原型逐字符。
- 事实与演示数据各有唯一来源：demo 构建器是演示数据唯一源，页面不写死数字。
- 没有实测不写通过；结论词只用 通过/失败/跳过/待人工。
- 令牌先于组件；正文 15px；三段外壳（原型声明条→侧栏→顶栏+页脚）；按钮 42–44px；断点 1180/900/600。
- 私密三出口（看板/导出/AI 上下文）共用同一过滤函数；页内写「N 条中私密 M 条」。
- 无判读列；派生值读时算不落库；风险模型（IPSS-R/IPSS-M）只登记医生原话，不自动计算。
- 数据层：ORDER BY rowid、显式 null、in_use、分节 *_title、分类不进趋势。
- 整页视图两入口（返回+关闭）、history 唯一真源、Esc 退一层；指标卡定高 194px 真 3D 翻转；AI 走 `mds:agent-draft` 只填不发。
- 非肿瘤红线不适用于 MDS（MDS 属髓系肿瘤），治疗线/疗程折叠可用肿瘤语义；但「预后、生存期、危险分层、疗效排序」仍禁自动生成。

## 二、病种专属需求（MDS）

1. **输血记录为一等实体**：日期、成分（红细胞/血小板）、单位数、输前血红蛋白/血小板、机构。看板聚合「近 90 天输血节奏」。来源：MDS 随访以输血依赖为核心负担（认领 issue 差异化矩阵 1）。
2. **血象随访按可比组组织**：同一指标跨方法/跨机构不合并、不做差、不连线；白细胞/中性粒细胞绝对值/血红蛋白/血小板四条基础线 + 医生登记的其他指标。
3. **疗程折叠卡**：去甲基化药物（如阿扎胞苷，按药品名登记不推荐）按「一次疗程」折叠；疗程内记录最低血象与输血关联。32 号模版。
4. **铁监测**：血清铁蛋白趋势 + 累计输血量并列对照（只对照不解读）；螯合药按用药记录登记。
5. **日常观察卡**：感染防护/出血观察/疲劳——只呈现用户已确认的医生医嘱原话；无医嘱时空态引导去问医生，不生成通用建议。
6. **确诊依据档案**：骨髓穿刺/活检、细胞遗传学、分子检测（SF3B1、TP53 等）**只登记结果原文与日期**，不做任何换算或解读；WHO/ICC 分类名登记医生原文。

## 四、验收口径

## 五、可回退默认值（无人值守，晨审追认）

| 决策点 | 默认值 | 理由 |
| --- | --- | --- |
| 服务主体 | MDS 患者本人 + 家属/照护者（家属代管场景为一等公民） | MDS 老年患者为主，家属常持材料 |
| 病程覆盖 | 确诊登记→观察等待/治疗→移植评估前，全病程；不做移植后管理 | 移植后属另一随访体系，避免半成品 |
| MinerU 解析 | 默认不接入；设置页留显式入口与「未接入」说明 | 无 token 不可用；按 18 号留六部件接线位 |
| 品牌占位名 | 小髓宝 MdsPal（MM 已用小浆宝 MyeloPal，区分明确） | 待用户追认，可整包替换 |
| 演示数据 | 两套合成档案：A 低危初诊观察等待（记录少、多处未知）；B 高危去甲基化治疗（疗程多、输血多、指标多） | 覆盖 MDS 两条典型路径 |
| 患者资料目录 | 未指定；装机后由用户在设置页显式选择 | 主目录/桌面/下载根/tmp 拒绝 |
