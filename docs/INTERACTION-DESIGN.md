# INTERACTION-DESIGN · 交互设计（28 号 IP1）

- 版本：v0.1.0 · M0 起草，M2 逐条实测
- 结构基准：小橙宝导航分组 + 小粉宝五 Tab/卡片体系（只抄结构）；滚动模型=视口锁高 #main 内滚；AI=右侧面板 25–45% 可拖。

## 关键交互（编号沿检查点清单）

- IP2/IP3：每场景一条路径；入口名=界面文案=导航 key 逐字一致；孤儿页=0。
- IP5/IP9/IP10/IP11：每个一级页有「和 AI 讨论」；`mds:agent-draft` 只填不发；手工/AI 同一事实层。
- IP6：每页显式编辑入口 ≤1，手工入口收进「⋯ 更多」，表单 ≤6 字段。
- IP7：数字输入（单位数、血红蛋白值）用数字键盘组件。
- IP8：更正=新增版本，全站无「不可恢复」。
- X1–X4：无头脚本穷举路径与计数。

## 页面级交互规范

- 输血节奏卡：柱状按月聚合 + 明细表联动高亮；点击柱过滤当月明细。
- 疗程折叠卡：`details.phase-fold`，收起显示「第 N 个疗程 · M 天 · 最低 Hb 值」，展开记天。
- 3D 指标卡：194px 定高、真 3D、背面折线（可比组内）；MT01–MT15 全项。
- 整页视图：输血明细大表、就诊材料预览走 page-view（A1–A10，双入口）。
- 疾病概要：顶栏 ？ → 整页面板四段（定义→医学资料规范和指南情况→治疗全景→发展趋势），P1–P9 全项；「按病期与线序排列」出口句（MDS 属肿瘤）。
- 隐私：家属协同记录默认私密；三出口共用过滤；页内「N 条中私密 M 条」。
