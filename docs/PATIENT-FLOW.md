# PATIENT-FLOW · 患者任务流

- 版本：v0.1.0 · M0
- 主体：MDS 患者本人（老年为主）+ 家属/照护者（资料代管一等公民）
- 状态：**0 患者访谈、0 临床审核**。以下流程为基于病种随访结构的假设，待真实访谈校正；不含一手引语。

## 核心闭环（输入→操作→结果→回顾）

### F1 确诊建档（刚确诊路径）

输入：血常规报告、骨髓穿刺/活检报告、细胞遗传学与分子检测报告（纸质/PDF）
操作：导入资料 → 逐项核对候选信息（只抄写不判断：项目名、结果原文、单位、日期、机构）→ 入档
结果：确诊依据档案（检查结果登记，含 WHO/ICC 分类医生原话）
回顾：档案页可查每项来源与原件状态

### F2 随访血象整理（每次复诊后）

输入：门诊血常规单
操作：录入或核对候选 → 选择方法/机构（可比组）→ 入档
结果：血象趋势（四条基础线）+ 与上次比较（不做疗效解读）
回顾：指标页看趋势；一图秀看全景

### F3 输血记账（输血后）

输入：输血记录单/出院小结
操作：录入日期、成分、单位数、输前血红蛋白、机构
结果：输血明细 + 近 90 天节奏卡更新
回顾：看板首屏；复诊时给医生看节奏

### F4 疗程记录（治疗路径）

输入：治疗记录/出院小结
操作：开新疗程折叠卡（药名、天数）→ 逐日记天数与当日血象最低点 → 疗程收卡
结果：疗程档案 + 计次
回顾：治疗页折叠卡收/展

### F5 就诊准备

操作：选时间窗 → 生成问题清单与资料摘要（私密过滤后）
结果：可导出的就诊材料（格式真实的文件）
回顾：导出历史

## 失败恢复

- 导入解析失败：原件保留，候选区标「解析失败，可手工录入」
- 数字写错：更正=新增版本，旧版本可查，无裸删除
- 断电/关闭：草稿保留本地

## 空态与首日

- 全新档案：看板给「三步开始」引导（导资料→建档案→记第一次血象），不显示空图表
- 两套合成演示档案供评审（A 低危初诊 / B 高危治疗），标注「合成示例」
